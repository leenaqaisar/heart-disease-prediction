Introduction¶

This project predicts whether heart disease is present or absent using the processed Cleveland dataset from the UCI Machine Learning Repository.

The project follows the workflow of the provided Titanic prediction notebook: importing libraries, loading data, preprocessing, feature selection, encoding, training, testing, prediction and feedback.

A Support Vector Classifier (SVC) is used for classification.

This is an educational project. Its predictions are not medical diagnoses.

Dataset Source¶

Step 3.2: Preprocessing Plan¶

All observations are retained.

Missing feature values will be filled using the most frequent value from the training data. This keeps imputed categorical values within the original UCI codes.

Features will then be standardized before training the SVC model.

Imputation and scaling are performed inside a pipeline after splitting the dataset. They learn only from training data, preventing test-data leakage.

Source: https://scikit-learn.org/stable/common_pitfalls.html

Step 5: Encode the Inputs and Output¶

Input Encoding¶

The input categories are already represented by numerical UCI codes, so an additional LabelEncoder is unnecessary.

These codes are retained to follow the reference notebook's simple SVC approach. However, numeric category codes imply distances between categories; one-hot encoding is a possible future improvement.

Output Encoding¶

The original diagnosis is converted into a binary target:

  • num = 0 → target 0: disease absent.
  • num = 1, 2, 3 or 4 → target 1: disease present.

Step 6.2: Build the Preprocessing and Training Pipeline¶

The pipeline contains:

  1. SimpleImputer: fills missing inputs using the most frequent training value.
  2. StandardScaler: standardizes feature values.
  3. SVC: trains a Support Vector Classifier with an RBF kernel.

The model uses fixed settings: C = 1 and gamma = "scale". The test set is not used to select these settings.

Sources:

  • https://scikit-learn.org/stable/common_pitfalls.html
  • https://scikit-learn.org/stable/modules/generated/sklearn.svm.SVC.html
In [224]:
model = Pipeline([
    ("imputer", SimpleImputer(strategy="most_frequent")),
    ("scaler", StandardScaler()),
    ("classifier", SVC(
        kernel="rbf",
        C=1.0,
        gamma="scale"
    ))
])

model.fit(X_train, y_train)

print("Model trained successfully.")

Step 6.3: Training-Only Cross-Validation¶

Five-fold stratified cross-validation is performed using only the training subset.

For each fold, the complete pipeline is fitted on that fold's training portion and evaluated on its validation portion.

The mean accuracy summarizes performance across folds. The standard deviation describes variation between fold scores.

Source: https://scikit-learn.org/stable/modules/cross_validation.html

Rows represent actual labels; columns represent predicted labels.

Conclusion and Limitations¶

This project demonstrates an end-to-end heart disease classification workflow using the UCI processed Cleveland dataset and an SVC pipeline.

The pipeline handles missing inputs and feature scaling using only training data. Evaluation includes training-only cross-validation and held-out test metrics.

The reported performance does not establish clinical reliability. The dataset is small and historical, and external validation has not been performed.

The target represents recorded angiographic disease status. It does not represent a prediction of future heart attacks.
